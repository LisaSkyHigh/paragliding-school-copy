# GitHub и Терминал: если пишет «Operation not permitted»

Если после `git status` вы видите:

`fatal: Unable to read current working directory: Operation not permitted`

это **не ошибка Git** — macOS **не даёт** программе (Терминалу или Cursor) читать папку, где лежит проект.

---

## Шаг 1. Дать Терминалу доступ к диску

1. Откройте **Системные настройки** (или **Системные параметры**) → **Конфиденциальность и безопасность**.
2. Слева найдите **Полный доступ к диску** (Full Disk Access).
3. Нажмите замок внизу, введите пароль Mac.
4. Включите переключатель для приложения **Терминал** (Terminal).
5. Если пользуетесь **встроенным терминалом в Cursor** — добавьте и **Cursor** в тот же список (или выполняйте команды в обычном Терминале из п. 2 ниже).
6. **Полностью закройте** Терминал и Cursor (⌘Q) и откройте снова.

---

## Шаг 2. Открыть именно «Терминал» macOS

1. В папке **Программы** → **Утилиты** → запустите **Терминал** (не вкладка в Cursor).
2. Скопируйте **одну строку** из файла проекта **`TERMINAL-PUSH-COMMANDS.txt`** (первая команда `cd "..."`) и нажмите Enter.
3. Введите: `git status` и Enter.

Если список файлов или «nothing to commit» — доступ восстановлен.

---

## Шаг 3. Дальше — как в `TERMINAL-PUSH-COMMANDS.txt`

По очереди: `git remote add origin …`, затем `git add -A`, `git commit …`, `git push` — всё там же, **без** кавычек ``` и без слова `bash`.

---

## Если шаг 1 не помог

- Попробуйте перенести папку проекта в другое место (например `~/Projects/paragliding-school`) без кириллицы в пути — иногда так стабильнее.
- Альтернатива без командной строки: приложение **GitHub Desktop** (бесплатно с сайта github.com) — можно подключить папку кнопками и сделать первый push из интерфейса.
