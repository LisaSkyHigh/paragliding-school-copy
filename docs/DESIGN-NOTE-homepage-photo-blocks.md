# Заметка: сетка ярких блоков под полоской цифр (как у конкурента)

**Статус:** только обсуждение. **В вёрстку пока не вносить** — до отдельного «да / окей».

## Идея потока первой страницы

1. **Первый экран** — одна большая фотография + утверждённый текст (hero).
2. **Полоска** — цифры (18 лет, 27 000+, 5 000+, 0, worldwide) + строка про приоритет безопасности.
3. **Новый слой** — сетка **крупных фото-блоков** с коротким заголовком на каждом; по клику — в ключевые разделы сайта (как у Super Fly: сетка 2×3, не «карточки с рамками», а именно **картинка = вход в раздел**).
4. **Ниже** — длинный текстовый блок «о школе» (всё, что сейчас идёт после полоски).

Сейчас блоки Try / Learn / Colombia стоят **ниже** по странице — позже можно **поднять** логику «картинка + заголовок» сразу под полоской, в духе референса.

## Варианты названий шести блоков (черновик для обсуждения)

Референс Super Fly: Shop / Paramotor / Kits / Learn / Used / Speed — у нас другой продукт, но **принцип шести разных смыслов** можно повторить.

Предложения (черновик):

| # | Направление | Рабочие названия на обсуждение |
|---|-------------|--------------------------------|
| 1 | С нуля + ближайший кемп | **Learn to fly** (как у них) — путь новичка, ближайшие даты |
| 2 | Уровни / куда расти | **Skill map** / «карта прогресса» / «ваш путь по уровням» — что за уровни, зачем каждый, куда ведёт |
| 3 | Снаряжение | **Paragliding shop** — продаём крылья и всё остальное |
| 4 | Поездки | **Expeditions** vs **Flying camps** — как в индустрии чаще говорят (нужно сверить с US-сайтами; часто: *trips*, *camps*, *guided tours*) |
| 5 | Истории | **Stories** / дневник и галерея прошлых кэмпов — то, что планировали в раздел stories |
| 6 | Связь | Лёгкий вход в **Contact** — не форма на всю плитку, а «написать / задать вопрос» |

Точные формулировки и **какие три дополнительные** смысла лучше всего лягут на ваш бренд — отдельно согласовать после GitHub.

## Лексика (вопрос на потом)

- **Expedition** — звучит «поход / экспедиция», часто для нестандартных локаций.
- **Camp** / **flying camp** — привычно для обучающих поездок в США.
- Можно смешать: например *Camps & expeditions* в одном блоке, если внутри два типа продуктов.

## Техническое

- Шесть плиток = шесть **ссылок** + шесть **изображений** из `public/` или CMS.
- Адаптив: на мобиле 1 колонка или 2; на десктопе 2×3 как у референса.
